# 记忆分层组件

本组件随呆猫补丁包默认安装，适配 MaiBot 1.3.19。公开包提供代码和空白语境模板；聊天记录、人物画像与记忆由使用者自己的实例积累。

## 保存规则

| 内容 | 保存方式 |
|---|---|
| 人物事实、称呼关系与互动偏好 | 长期保存，依照明确的后续更正维护 |
| 共同经历、约定和有趣互动 | 长期保存其内容与来历 |
| 最近的近况、临时安排、当次感受 | 默认 7 天；明确未来安排至少保留到记录中的目标日期 |
| 明确要求记住、手工置顶 | 按标记长期保留 |
| 运维和机器人规则材料 | 单独分类 |
| 到期近期内容 | 冷归档，退出日常检索与人物画像，原文继续保留 |

读取记忆和刷新画像不延长近期内容的期限。人物画像取材于当前场合可见且有效的事实与经历，共同故事可按话题检索。记忆正文使用自然句子，类型、来源、时间和范围写入记录字段。

已有维护循环负责到期归档；每周候选报告写到实例的 `data/a-memorix/retention-reports`。每月整理 30 天以前的旧自动画像快照，保留每人最新一份和手工版本。日期解释和本地报告沿用 UTC+8。

## 语境配置

总安装器会将 `memory_context.example.json` 作为初始模板合并到实例的 `config/memory_context.json`。运行时通过 MaiBot 的实例根目录解析该位置。

- `defaults.context`：所有聊天通用的场景说明。
- `defaults.names`、`defaults.terms`：可按需填写称呼与术语。
- `defaults.bots`：其他机器人账号，辅助分辨发言来源。
- `groups`：按群号或会话 ID 配置各场景自己的语境。
- `owner_user_ids`、`private_terms`：可选的私人范围设置。初始均为空，普通记忆先按所在会话保存；明确设置主人后，相关私人记录保存其明确归属。

安装组件本身不打开或迁移聊天数据库。已有未分类内容在运行时按来源做兼容分类：人物事实继续长期保存，普通聊天摘要按近期规则处理。想保留的旧重要经历可先设置相应长期类别或记住标记。

## 单独查看源码补丁

通常使用补丁包根目录的总安装器即可。此入口供需要单独预览源码改动的使用者使用：

```text
python memory/install.py --source-root "<MaiBot Python 环境的 site-packages/src>"
```

默认只显示预览。指定 `--apply` 才写入；应用源码补丁时先停止目标 MaiBot，完成后再启动。安装器检查相邻的 `maibot-*.dist-info/METADATA`，只接受版本 1.3.19。

补丁由 14 个现有文件的上下文修改和 3 个新增模块组成。目标片段以外的改动保留；同一位置存在其他修改时报告冲突，全部预检通过后才开始写入。重复安装同一内容会跳过已经完成的部分。

独立安装默认将原文件备份到源码根目录旁的 `daimon-memory-backups`；也可通过 `--backup-root` 指定位置。备份中的 `backup.json` 列出原文件是否存在，原有文件按相对路径保存。恢复时关闭目标实例，恢复这些原文件，并移除清单中标为原先不存在的新增模块。

## 供总安装器调用

`install.py` 只使用 Python 标准库。导入时不会读取实例配置或写入文件。

- `plan(source_root)`：返回版本、变化文件数和文件清单。
- `plan_install(source_root)`：完成全部预检后，返回仅有变化的操作，每项含 `target`、`relative_path`、`before`、`after`；不执行写入，供总安装器统一备份与应用。
- `apply(source_root, backup_root=None)`：独立应用，先保存原字节备份；写入失败时回退本次已经写入的文件。

代码许可和上游来源见补丁包根目录的许可证与 NOTICE。
