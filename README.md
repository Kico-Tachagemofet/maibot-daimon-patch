# MaiBot 呆猫补丁包

让已经安装的 MaiBot 使用呆猫人设、当拍牌骰与茭杯门控，并把人物事实、共同经历和近期记忆分层保存。

这是 0.1.0-rc2 发布候选，面向 MaiBot **1.3.19**。使用运行 MaiBot 的 Python 环境执行安装器；插件依赖该环境已有的 maibot_sdk，配置合并使用 tomlkit。

## 默认包含

| 组件 | 用途 |
|---|---|
| 呆猫人设 | 艾路猫风格、熟人互动、Daimon／载体设定和工具路由 |
| 呆猫底色与门控 | 一拍大阿卡纳、星骰及按需茭杯；后续工具复用同拍结果 |
| 塔罗与梅花 | 印象／运势等塔罗解读，以及具体事情的梅花易数 |
| 神祇资料 | 本地神祇卡与名称目录 |
| 羊距骨神谕 | 显式请求下的五羊距骨、56 签资料 |
| 外应探针 | 观察群聊里的相关线索，默认 dry_run，只记录判定 |
| 记忆分层 | 近期默认 7 天；人物事实和共同经历长期保留；画像、检索、冷归档一并处理 |

安装包使用空白记忆语境模板。每位安装者自己的聊天、关系和经历从自己的实例中积累。

## 安装

先按 MaiBot 的说明安装 1.3.19 并配置自己的模型、账号和消息适配器。关闭准备安装补丁的实例，然后在本包目录执行：

```shell
python install.py --maibot-root "/path/to/maibot"
```

默认展示将要修改的文件。确认路径后执行：

```shell
python install.py --maibot-root "/path/to/maibot" --apply
```

需要设置主人与机器人账号时，可追加 `--owner-id "你的账号" --bot-id "机器人账号"`。这些值由安装者填写。

安装器默认从当前 Python 环境寻找 MaiBot 的源码；使用自定义环境时，可追加 `--source-root "/path/to/site-packages/src"`。预览会检查支持版本及补丁上下文。保留使用者已有模型配置和无关配置字段；首次安装合并呆猫人设，后续安装保留已有的人设和插件配置定制。

插件装到实例的 `plugins`，资料装到 `data/daimon-resources`。运行 MaiBot 时以其实例目录为工作目录；使用其他工作目录时，设置 `MAIBOT_INSTANCE_DIR` 为实例根目录。

## 使用与记忆

日常回复使用 `daimon_pulse`；具体事情接梅花，运势或印象接塔罗。茭杯参与门控时，后续工具按当拍结果决定是否继续。羊距骨使用明确入口。具体工具说明见 [plugins/README.md](plugins/README.md)。

距骨按人、按题保存拒杯与回答状态：同题三次拒杯后暂停当天距骨求问；完成发送后才计成功次数；已答复用原签，未完成的原签继续发送。澄清确认接回原问题，模型判题失败时走澄清。每小时5次、每天12次及30秒成功间隔只用于距骨；梅花和塔罗保留原脉搏门控与基础冷却。

外应插件默认 `dry_run=true`。需要它实际发言时，在自己的 `plugins/kico_waiying/config.toml` 中调整该项，并填写机器人账号与适用群。塔罗图片默认关闭，卡面图片不随本包提供。

记忆分类使用 `fact`、`shared_experience`、`recent_event` 和 `rule_note`。近期内容默认 7 天，明确未来事项按其期限保留；明确要求记住或手工置顶的内容按标记保留。过期近期内容冷归档，退出日常画像和检索，原文仍保留。

可以在实例的 `config/memory_context.json` 填写自己的群内称呼、术语和账号对应。语境进入记忆提取与摘要生成，记忆正文保持自然叙述。

## 备份、恢复与版本

安装器为本次会改动的文件建立备份和收据。恢复使用安装输出的收据路径：

```shell
python install.py --maibot-root "/path/to/maibot" --restore "/path/to/receipt.json" --apply
```

去掉 `--apply` 可以先预览恢复清单。恢复前会比较安装后的文件内容；安装后另行编辑过的文件需要先处理对应差异。恢复作用于本次安装文件，聊天数据库由实例自身管理。

目前支持范围是 1.3.19。升级 MaiBot 后应重新对齐源码补丁，先在副本验证，再应用到自己的实例。
