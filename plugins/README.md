# 呆猫功能插件

这六个目录一起安装到 MaiBot 的 plugins 目录，适配的宿主版本为 MaiBot 1.3.19。

| 目录 | 作用 |
|---|---|
| daimon_pulse | 产生同一拍的大阿卡纳、星骰和可选茭杯，供回复与后续工具共同使用 |
| user_tarot-card-plugin | 消化当拍塔罗与星骰；保留显式塔罗入口 |
| kico_meihua | 具体问题的梅花易数，与当拍牌骰合参 |
| kico_deity_lore | 本地神祇资料与缺失时的搜索要求 |
| kico_astragaloi | 显式羊距骨神谕入口 |
| kico_waiying | 外应探针，默认只记录判定；dry_run=false 后才自动发言 |

## 路径与模型

运行目录通常是 MaiBot 工作目录；显式设置 MAIBOT_INSTANCE_DIR 时，以该目录为准。
三个协同插件共同读写 temp/daimon_pulse_state.json。
资源安装在 data/daimon-resources 下的 tarot-meanings、deity-cards 和 astragaloi 目录。
示例配置中的相对资源路径也以 MAIBOT_INSTANCE_DIR 或工作目录为起点。
模型名默认留空，沿用使用者配置的 replyer 任务。

各目录的 config.example.toml 是公开默认值；安装者可复制成 config.toml，或由宿主生成默认配置。
神祇资料插件直接读取约定资源目录，不需要单独配置文件。
外应插件的 bot_user_ids 可填写自己的机器人账号，群名单按安装者的使用场景填写。

## 羊距骨求问规则

距骨自带一套按人、按题记账的守门，不与其他占卜共用配额：

- 掷杯在起卦之前；笑杯、阴杯不掷骨，只记这一次摇头。
- 摇头按「提问者 + 这件事」记录，同一件事连续三次被拒后暂停此人当天的距骨求问；换一件事重新计数，圣杯清零。
- 成功答完才计数：每滚动一小时 5 次、每天 12 次、两次之间至少 30 秒；额度不足时在掷杯前直接说明，不消耗杯。
- 同一件事再次询问时复用原签，不重抽、不扣次数；起卦后若解读或发送失败，保留这份结果并在下次继续完成。
- 判断“同一件事”先看是否明确回复了那道题或那支签，再看规范化后是否完全相同；近似文本只作为候选，交给模型判定，拿不准时反问一句「还是刚才那件，还是换一件」。这两个短句直接在群里回就行，不用再带 `/距骨`；回「还是那件」会接着处理刚才那道题，回「换一件」会请对方把新题说出来。模型判断失败时按“拿不准”处理，不会硬接到旧题上。
- 取不到真实发送者时直接拒答并记日志，不拿群会话号顶替某个人；不同匿名请求不会共用拒杯次数或原签。
- 账本默认写入 `temp/astragaloi_guard.json`，可用 `state_path` 改到别处；日配额与当天暂停随日期重置，滚动一小时与六小时窗口各按自己的时间保留。

起卦后若账本无法写入，原签暂存在当前插件实例的内存里，待写入恢复后继续原结果。这种临时保留依赖当前实例存活；插件重载、进程重启或断电后的恢复不在这条内存重试保证内。
